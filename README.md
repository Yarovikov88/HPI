# Персональный сайт-портфолио Андрея Яровикова

Этот репозиторий содержит исходный код для персонального сайта-портфолио ya88.ru. Сайт разработан как витрина ключевых компетенций, проектов и методологий в области управления личным развитием и IT-проектами.

## О проекте

Сайт представляет собой интерактивную платформу, раскрывающую следующие темы:

- **Архитектура личного развития:** Системный подход и фреймворки для управления жизнью.
- **RnD-лаборатория:** Эксперименты и исследования в области личной эффективности.
- **HPI (Human Potential Index):** Авторский сервис и методология для оценки и развития человеческого потенциала.
- **Услуги и сотрудничество:** Консультации, наставничество и разработка IT-решений.

## Структура проекта

Проект построен на React и Vite и имеет следующую структуру:

- `src/components`: Общие переиспользуемые компоненты (Header, Footer, Timeline и т.д.).
- `src/pages`: Компоненты для каждой отдельной страницы сайта (`/architecture`, `/rnd` и т.д.).
- `src/data`: Статические данные, например, для таймлайна "Мой путь".
- `docs`: Документация проекта, включая `structure.md` (эталон текстов) и `CHANGELOG.md`.

## Технологический стек

- **Фреймворк:** React
- **Сборщик:** Vite
- **Язык:** TypeScript
- **Стилизация:** CSS Modules
- **Роутинг:** React Router DOM

## Запуск проекта

1.  Установите зависимости:
    ```bash
    npm install
    ```
2.  Запустите dev-сервер:
    ```bash
    npm run dev
    ```
3.  Откройте [http://localhost:5173](http://localhost:5173) в вашем браузере.
