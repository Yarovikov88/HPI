## Как тестировать

### 1. Запуск тестовой страницы
Перейдите по адресу: `http://localhost:3000/test-metrics`

### 2. Тестирование в основной системе
1. Войдите в систему
2. Перейдите к PRO диагностике
3. Выберите любую сферу
4. В разделе "Метрики" должны отображаться три поля вместо одного

## Структура данных

### В базе данных
Вопросы категории "metrics" содержат поле `metrics` с массивом объектов:
```json
{
  "metrics": [
    {
      "name": "Часы вместе в неделю",
      "unit": "ч",
      "type": "number"
    }
  ]
}
```

### В ответах пользователя
Ответы на метрики сохраняются в поле `text` в формате JSON:
```json
{
  "what_measure": "Время, проведенное вместе",
  "target_value": 20,
  "unit": "часов"
}
```

## Валидация

Форма метрик считается заполненной только когда заполнены все три поля:
- `what_measure` - не пустая строка
- `target_value` - число
- `unit` - не пустая строка
