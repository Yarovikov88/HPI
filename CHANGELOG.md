# Changelog

Все значимые изменения этого проекта будут документироваться в этом файле.

## [0.4.1] - 2024-07-22

### Added
- Настроен пререндеринг (SSG) с помощью `vite-react-ssg` для всех страниц сайта. Это значительно улучшает SEO, так как поисковые роботы теперь получают полностью готовый HTML.

### Changed
- Проведена реорганизация структуры приложения для поддержки SSG:
  - Создан компонент `Layout` для общей разметки страниц.
  - `App.tsx` переработан для экспорта массива роутов.
  - `main.tsx` обновлен для инициализации через `ViteReactSSG`.

### Fixed
- Устранены проблемы с SEO, связанные с рендерингом на стороне клиента (CSR).

## [0.4.0] - 2024-07-21

### Added
- Созданы и наполнены контентом все основные разделы сайта:
  - "Архитектура личного развития" (`/architecture`)
  - "Моя RnD-лаборатория" (`/rnd`)
  - "Услуги и сотрудничество" (`/collaboration`)
  - "Поиск смыслов на карте и в книгах" (`/meanings`)
  - "Перезагрузка и восстановление" (`/reboot`)
- Добавлены маршруты и навигация для всех новых страниц.
- Создан общий стиль оформления для контентных страниц (`Page.module.css`).

## [v0.3.1] - 2024-07-20
- Персонализация главной страницы: добавлено фото, новый подзаголовок
- Переименование и обновление всех разделов (Сервис HPI, Моя библиотека, Карта поиска смыслов и др.)
- Улучшение структуры и текстов на главной странице
- Обновление цветовой схемы, акцент на экспертности и уникальности

## [v0.1.0-dev] - 2025-06-29
- Первый рабочий MVP на React + Vite + CSS Modules
- Оформлена концепция и структура сайта
- Подключён git и GitHub
- Добавлен файл concept.md
